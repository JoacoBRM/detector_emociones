Contexto
En la clase «Fine-tuning y evaluación de modelos de lenguaje» ajustamos DistilBERT para clasificar frases en seis emociones: tristeza, alegría, amor, ira, miedo y sorpresa. Un modelo que solo funciona dentro de un notebook no lo puede usar nadie más. En este proyecto convertirán ese modelo en una aplicación web con Streamlit, donde cualquier persona escribe una frase y recibe la emoción que expresa.
Objetivo
Al finalizar el proyecto, el equipo:
Desarrollar una aplicación web con Streamlit que reciba una frase, la clasifique con el modelo ajustado en clase y presente el resultado de forma clara, mostrando también qué tan seguro está el modelo de su respuesta.
Requisitos Obligatorios7
Entrada de texto: un campo donde el usuario escribe una frase y un botón para analizarla
Resultado principal: la emoción detectada y su probabilidad (confianza) en porcentaje
Probabilidades completas: un gráfico con la probabilidad de las seis emociones
Carga eficiente del modelo: el modelo debe cargarse una sola vez con @st.cache_resource
Validaciones: mensaje claro si la frase está vacía o si no se encuentra la carpeta del modelo
Aviso de idioma: indicar al usuario en qué idioma fue entrenado el modelo elegido, inglés o español
Modelo propio: usar un modelo entrenado por el equipo, no uno ya ajustado y descargado de internet. Pueden elegir el modelo en inglés del notebook de clase (Bloque 4.4, modelo_emociones_distilbert) o un modelo en español
Funcionalidades Adicionaleselegir 2
Importante
Elijan al menos dos de las siguientes funcionalidades.
Umbral de confianza: advertir cuando la emoción principal tiene baja probabilidad, con un control para ajustar el umbral
Análisis por lotes: varias frases (una por línea o un archivo CSV) con una tabla de resultados descargable
Historial: registro de las frases analizadas en la sesión usando st.session_state
Frases de ejemplo: botones que cargan frases de prueba en el campo de texto
Despliegue: aplicación publicada en Streamlit Community Cloud con el modelo alojado en Hugging Face Hub
Comparación de modelos: mostrar lado a lado el resultado del modelo ajustado y el de la línea base TF-IDF + regresión logística
Entregables4
Repositorio en GitHub con app.py, requirements.txt, README.md (descripción, instalación y ejecución, capturas de pantalla y funcionalidades implementadas) y un .gitignore que excluya la carpeta del modelo, que pesa unos 250 MB mientras GitHub no acepta archivos de más de 100 MB
Video de demostración y defensa de 2 a 3 minutos, con la app funcionando con al menos cinco frases, incluido un caso en que el modelo se equivoque, en el que los integrantes defienden su proyecto

streamlit run app.py

Pistas

pipeline("text-classification", model="modelo_emociones_distilbert") carga el modelo y el tokenizador guardados.
Al llamar al pipeline, top_k=None devuelve la probabilidad de todas las emociones y truncation=True evita errores con frases largas.
Streamlit vuelve a ejecutar todo el script en cada clic. Por eso el modelo se carga dentro de una función decorada con @st.cache_resource.
